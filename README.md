# ayushbhagwat.vercel.app

My portfolio. Vite + React + TypeScript + Tailwind, static build, deployed on Vercel.

- All text lives in [`src/content.ts`](src/content.ts). Edit that, not the components.
- The resume button serves `public/ayush_resume.pdf`; replace the file to update it.
- `public/og.png` is the link preview for X / LinkedIn / Slack.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # type-check + production build into dist/
```
